# Restaurant-Management-System
Restaurant Management System is a modular Java POS solution for small-to-medium restaurants, featuring three apps (Order, Kitchen, Management) with real-time order processing, stock control via MySQL triggers, dynamic pricing/discounts, and PDF reporting to streamline operations.

# Restaurant Management System

A standalone Java-based POS solution designed to minimize human error, streamline communication between front-of-house and kitchen teams, and automate stock control for small–medium restaurants.

**Author:** Adarsh Pandey & Jiya Bhati

## 🚀 Features

- **Multi‐app Architecture**  
  - **Order** (waiter PDA/terminal)  
  - **Kitchen** (large display of active orders)  
  - **Management** (menu, stock, offers, seating)
- **Real-time Stock Control** via MySQL triggers
- **Flexible Discounts & Offers** engine
- **Responsive GUI** fits from PDAs (480×320) to large monitors
- **Automated Reports & Statistics**

---

## 🛠️ Tech Stack

- **Language:** Java (JDBC, Swing/JavaFX)
- **Database:** MySQL
- **Build:** Maven
- **Version Control:** Git
- **UML & Reporting:** PlantUML, LaTeX for report
